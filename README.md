# Doctor-Only Prescription Generation System (Frontend)

This project is a frontend prototype for an **AI-powered prescription safety system** designed for hackathons.

## Features
- 3-Level doctor verification
- Medical license upload
- Secure password creation
- Doctor-only login
- OTP-based password reset
- Privacy-first UI

## Tech Stack
- HTML
- CSS (Glassmorphism)
- JavaScript (Vanilla)

## How to Run
1. Clone this repository
2. Open `index.html` in a browser
3. No backend required for demo

## Security Notes
- Password validation on frontend
- Backend will use bcrypt/argon2
- No patient data stored

## Future Scope
- Backend & database
- AI agent for prescription validation
- QR-based prescription verification
